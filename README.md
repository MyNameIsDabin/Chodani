# Chodani

> AI 로 만든 프로젝트입니다. 코드와 아이콘, 이 문서까지 대부분을 Anthropic 의
> Claude 와 함께 썼습니다. 무엇을 만들지와 어떻게 동작해야 하는지는 사람이
> 정하고, 구현과 다듬기를 AI 가 맡는 식으로 진행했습니다.

애니메이션 · VFX 레퍼런스 분석용 **프레임 정확 비디오 플레이어**.
Tauri(Rust + WebView2)로 만들어 실행 파일 하나로 동작합니다.

## 무엇을 하나

- **프레임 단위 정지·이동** — 1프레임 / N프레임 / 1초 단위 앞뒤 이동, 프레임 번호 직접 입력
- **프레임 정확도** — ffprobe로 각 프레임의 실제 표시 시각(PTS)을 읽어 그 값으로 시크합니다.
  가변 프레임레이트(GIF 변환본, 화면 녹화 등)에서도 프레임 번호가 어긋나지 않습니다.
- **메모 / 즐겨찾기** — 프레임에 메모와 색을 남기고, 목록에서 클릭해 그 프레임으로 점프
- **어니언 스킨** — 앞뒤 N프레임을 반투명하게 겹쳐 보기 (색 구분, 혼합 모드, 간격 조절)
- **프레임 고정 비교** — 기준 프레임을 고정해 나란히 보거나, `\` 키로 현재 프레임과 겹쳐 전환
- **A–B 구간 반복**, 재생 속도 0.1x~2x
- **PNG 내보내기** — 현재 프레임, 또는 모든 마커 프레임 일괄 저장
- **확대 / 이동** — 휠 확대, 드래그 이동
- **자동 저장** — 마커·구간은 영상별로 자동 저장되며 다시 열면 복원됩니다

지원 입력: `mp4` `mov` `mkv` `webm` `avi` `gif` 등 ffmpeg가 읽는 모든 형식,
그리고 YouTube를 비롯한 yt-dlp 지원 사이트 링크.

## 필요한 것

| 도구 | 용도 | 없을 때 |
| --- | --- | --- |
| **ffmpeg / ffprobe** | 프레임 분석, GIF·MKV 등 변환 | 필수. PATH에 있어야 합니다 |
| **yt-dlp** | 링크 불러오기 | 앱의 `최근` 탭에서 버튼 한 번으로 설치 |

## 설치

[Releases](https://github.com/MyNameIsDabin/Chodani/releases/latest)에서
`Chodani_x.y.z_x64-setup.exe`를 받아 실행하세요.

설치본은 시작할 때 GitHub Releases를 확인해 새 버전이 있으면 알려줍니다.
`최근` 탭 → `버전`에서 수동 확인하거나 자동 확인을 끌 수 있습니다.

## 빌드

```powershell
npm install
npm run tauri dev      # 개발 실행
npm run tauri build    # 배포용 exe + 설치 프로그램
```

빌드 결과: `src-tauri/target/release/chodani.exe`

## 릴리스

태그를 밀면 GitHub Actions가 빌드·서명하고 Release를 만듭니다.
앱은 그 Release의 `latest.json`을 보고 업데이트를 감지합니다.

```powershell
npm run bump 0.1.1                 # package.json · tauri.conf.json · Cargo.toml 동시 갱신
git commit -am "v0.1.1"
git tag v0.1.1
git push --follow-tags
```

버전은 세 파일에 모두 들어 있고, `tauri.conf.json`과 `Cargo.toml`이
어긋나면 빌드는 되지만 업데이트가 안 잡힙니다. 그래서 `npm run bump`로
한 번에 바꾸도록 해 두었습니다.

### 서명 키

업데이트 패키지는 minisign 키로 서명되며, 앱에 심어진 공개키와 맞아야만
설치됩니다. 저장소에는 공개키만 들어 있습니다(`tauri.conf.json`).

| | 위치 |
| --- | --- |
| 개인키 | `~/.tauri/chodani.key` (로컬) + 저장소 시크릿 `TAURI_SIGNING_PRIVATE_KEY` |
| 개인키 암호 | 저장소 시크릿 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` (빈 값) |

**개인키를 잃어버리면 기존 설치본에 업데이트를 보낼 수 없습니다.**
키를 새로 만들면 사용자는 새 버전을 수동으로 다시 설치해야 합니다.

## 단축키

| 키 | 동작 | 키 | 동작 |
| --- | --- | --- | --- |
| `Space` | 재생 / 정지 | `M` | 메모 추가 |
| `←` `→` (또는 `,` `.`) | 1프레임 이동 | `B` | 즐겨찾기 토글 |
| `Shift` + `←` `→` | N프레임 이동 | `I` / `O` | 반복 A / B 지정 |
| `Ctrl` + `←` `→` | 1초 이동 | `L` | 구간 반복 |
| `Home` / `End` | 처음 / 끝 | `N` | 어니언 스킨 |
| `1`…`9` | n번째 마커로 이동 | `P` | 현재 프레임 고정 |
| `[` `]` | 스텝 크기 조절 | `\` (누르는 동안) | 고정 프레임 겹쳐보기 |
| `0` | 확대 초기화 | `E` | 현재 프레임 PNG 저장 |
| `?` | 단축키 도움말 | | |

## 동작 방식

```
링크 ──yt-dlp──▶ 스트림 URL ─┐
                             ├─▶ 로컬 HTTP 서버 ──▶ <video>  (재생·오디오)
파일 ──ffmpeg──▶ 캐시 MP4  ──┘     (byte-range,        │
       (필요할 때만)                 동일 출처 CORS)     ├─▶ canvas  (어니언스킨·PNG)
                                                        │
        ffprobe ──▶ 프레임 PTS 인덱스 ──▶ 프레임 ↔ 시간 매핑
```

로컬 서버를 한 겹 두는 이유는 두 가지입니다.
탐색에 필요한 byte-range 응답을 보장하고, 로컬 파일이든 원격 스트림이든
**같은 출처**로 내려보내 캔버스가 오염되지 않게 하려는 것입니다.
캔버스가 오염되면 어니언 스킨과 PNG 내보내기가 동작하지 않습니다.

`<video>`의 시크는 요청한 시각을 포함하는 프레임으로 해석되므로,
프레임 경계가 아니라 **프레임 표시 구간의 중앙**을 목표로 시크합니다.
반올림 오차로 한 프레임 밀리는 경우를 없애기 위한 것입니다.

## 유튜브에 대해

유튜브 iframe 플레이어는 프레임 단위 제어가 불가능합니다(시크 정밀도가 낮고
프레임 번호를 알 수 없음). 그래서 yt-dlp로 링크에서 실제 스트림 주소만 얻어
로컬 파일과 똑같은 경로로 재생합니다. 프레임 정확도는 동일합니다.

- **고화질 (소리 없음)** — 영상 전용 스트림. 레퍼런스 분석에는 이쪽을 권장합니다.
- **소리 포함 (화질 낮음)** — 오디오가 합쳐진 단일 스트림.
- **내려받아 열기** — 스트림 주소는 시간이 지나면 만료됩니다. 오래 붙잡고 볼
  영상이라면 이 옵션이 안정적입니다. `%LOCALAPPDATA%\Chodani\cache`에 저장됩니다.

## 저장 위치

```
%APPDATA%\Chodani\projects\*.json   마커·메모·구간 (영상별 자동 저장)
%APPDATA%\Chodani\recent.json       최근 목록
%APPDATA%\Chodani\bin\yt-dlp.exe    앱에서 설치한 yt-dlp
%APPDATA%\Chodani\cache\            변환·다운로드 캐시
```
